# MCP 연결 가이드 분석

- 요청(2026-11-17, 사용자): `https://gyungchung-mcp.vercel.app/mcp-guide`에 비전공자도 따라 할 수 있는 가이드 문서와 설명 영상을 만든다.
- 독자: 경충FC 운영진과 회원. 개발 지식이 없고, ChatGPT나 Claude를 쓰는 사람.
- 근거: 첫 실제 연결에서 "OAuth 콜백 데이터가 누락되었습니다" 오류와, 연결 뒤 AI가 도구를 쓰지 않는 문제가 나왔다. 가이드에 두 경우의 해결법을 넣는다.
- 가정: 화면 콘셉트 3종 제시는 생략했다. 사용자가 중단 없이 만들라고 지시했고, 경충 웹의 색과 서체 체계를 그대로 따랐다. 디자인 방향을 바꾸려면 이 문서에서 다시 정한다.
- 확인하지 못한 것: ChatGPT의 플랜별 지원 범위(자료가 엇갈림), ChatGPT와 Claude 화면의 한국어 버튼 이름. 그래서 버튼 이름은 공식 문서의 영어 표기로 적었다.
- 완료 기준: 주소에서 문서와 영상이 열리고, 모바일과 데스크톱, 밝은 화면과 어두운 화면에서 읽을 수 있다.
