연결하기 말로 시키기 문제 해결

AI에게 말로 시키면 경충 일이 됩니다

ChatGPT나 Claude에 경충을 한 번만 연결하세요. 3분이면 끝나고, 그다음부터는 말로 확인하고 바꿉니다.

연결 시작하기 오류가 났어요

1분 53초 설명 영상입니다. 자막이 들어 있어 소리를 꺼도 됩니다.

영상 내용을 글로 보기

ChatGPT나 Claude에 경충을 연결하면, 말로 시켜서 일정과 참석, 회비를 확인하고 바꿀 수 있습니다. 연결은 한 번만 하면 되고 3분이면 끝납니다.

준비할 것은 세 가지입니다. 컴퓨터의 Chrome 브라우저, 경충 전화번호와 비밀번호, 그리고 ChatGPT나 Claude 계정입니다.

먼저 가이드 문서에서 주소 복사 버튼을 눌러 연결 주소를 복사합니다.

ChatGPT를 쓴다면 플러그인 화면을 열고, 더하기 버튼을 눌러 Add custom MCP server를 고릅니다.

이름에 경충이라고 적고, 복사한 주소를 붙여 넣은 다음 Create as a plugin을 누릅니다.

Claude를 쓴다면 Customize의 Connectors에서 Add를 누르고, 같은 주소를 붙여 넣습니다.

그러면 경충 로그인 화면이 뜹니다. 웹과 같은 전화번호와 비밀번호로 로그인하고 연결 승인을 누릅니다. 꼭 그 창 안에서 끝까지 진행하세요.

이제 새 대화에서 말로 시켜 보세요. 예를 들면, 이번 주 참석자 명단 알려 줘.

무언가를 바꾸라고 하면 바로 저장하지 않습니다. 바뀔 내용을 먼저 보여 주고, 내가 좋다고 해야 저장합니다.

오류가 나면 Chrome 시크릿 창에서 다시 연결해 보세요. 자세한 내용은 가이드 문서에 있습니다.

시작하기 전에 세 가지만 준비하세요

  • 컴퓨터의 Chrome 브라우저휴대폰보다 컴퓨터에서 연결하는 것이 쉽습니다. 연결은 한 번만 하면 되고, 그 뒤에는 휴대폰에서도 쓸 수 있습니다.
  • 경충 전화번호와 비밀번호경충 웹이나 앱에 로그인할 때 쓰는 것과 같습니다. 따로 가입하지 않습니다.
  • ChatGPT 또는 Claude 계정둘 중 쓰는 것 하나면 됩니다. ChatGPT는 무료 플랜에서 연결 메뉴가 보이지 않을 수 있습니다.

쓰는 AI를 고르고 순서대로 따라 하세요

화면의 글자가 영어로 나올 수 있어서 버튼 이름은 영어 그대로 적었습니다. 글자가 조금 달라도 위치와 순서는 같습니다.

  1. 플러그인 화면을 엽니다

    Chrome에서 chatgpt.com/plugins를 엽니다. 로그인하라고 나오면 ChatGPT 계정으로 로그인합니다.

  2. 새 연결을 만듭니다

    + 버튼을 누르고 Add custom MCP server를 고릅니다.

  3. 이름과 주소를 적습니다

    • 이름경충
    • 설명경충FC 일정, 참석, 회비 관리
    • 주소위에서 복사한 주소를 붙여 넣습니다 (Ctrl + V)

    인증 방식을 고르는 칸이 있으면 OAuth를 고릅니다. 이미 골라져 있으면 그대로 둡니다.

  4. 만들기를 누릅니다

    안내 문구 아래의 I understand and want to continue에 표시하고 Create as a plugin을 누릅니다.

  5. 경충에 로그인하고 승인합니다

    작은 창에 경충 로그인 화면이 뜹니다. 아래 로그인 안내대로 하면 됩니다.

  6. 새 대화에서 경충을 부릅니다

    새 대화를 열고 입력 칸에 @를 쳐서 경충을 고른 다음, 하고 싶은 말을 적습니다.

ChatGPT는 메뉴 이름과 위치를 자주 바꿉니다. 위 메뉴가 보이지 않으면 설정에서 Apps, Connectors, Plugins 같은 이름을 찾아 보세요. 그래도 없으면 쓰는 플랜에서 지원하지 않는 것일 수 있습니다.

  1. 커넥터 화면을 엽니다

    Chrome에서 claude.ai에 로그인하고, 왼쪽 메뉴에서 Customize를 누른 뒤 Connectors를 고릅니다.

  2. 새 연결을 만듭니다

    + Add를 누르고 Add custom connector를 고릅니다.

  3. 이름과 주소를 적습니다

    • 이름경충
    • 주소위에서 복사한 주소를 붙여 넣습니다 (Ctrl + V)

    적은 뒤 Continue를 누릅니다.

  4. 나머지는 그대로 두고 추가합니다

    인증 설정 화면은 바꾸지 않고 Continue를 누릅니다. 로그인 시점은 Sign in now를 고르고 Add를 누릅니다.

  5. 경충에 로그인하고 승인합니다

    경충 로그인 화면이 뜹니다. 아래 로그인 안내대로 하면 됩니다.

  6. 대화에서 경충을 켭니다

    대화 입력 칸 왼쪽 아래의 +를 누르고 Connectors에서 경충을 켠 다음, 하고 싶은 말을 적습니다.

Claude 무료 플랜은 직접 추가하는 연결을 하나만 만들 수 있습니다. 팀 플랜에서는 관리자가 먼저 추가해야 합니다.

경충 로그인 화면이 뜨면

연결하는 도중에 오른쪽과 같은 화면이 나옵니다. 경충이 맞는지 확인하는 단계입니다.

  1. 경충 웹에서 쓰는 전화번호와 비밀번호를 적고 전화번호로 로그인을 누릅니다.
  2. 어떤 AI가 연결하려는지 보여 줍니다. 내가 방금 연결한 AI가 맞으면 연결 승인을 누릅니다.
  3. 창이 닫히고 AI 화면으로 돌아오면 연결이 끝난 것입니다.

이 화면이 뜬 바로 그 창에서 끝까지 진행하세요. 주소를 복사해 다른 창이나 경충 앱에서 열면 연결이 실패합니다.

잘 안 될 때

"OAuth 콜백 데이터가 누락되었습니다"라고 나와요

경충 로그인 화면이 처음 열린 창이 아닌 다른 창에서 진행됐을 때 나옵니다. 컴퓨터에 경충 앱이 설치돼 있으면 자주 생깁니다. 이렇게 다시 해 보세요.

  1. Chrome에서 Ctrl + Shift + N을 눌러 시크릿 창을 엽니다.
  2. 그 창에서 ChatGPT에 로그인하고 처음부터 다시 연결합니다.
  3. 작은 창에 뜬 경충 화면 안에서 로그인과 승인을 끝냅니다.

ChatGPT 컴퓨터용 앱이 아니라 Chrome 브라우저에서 해 주세요.

경충 로그인 화면이 아예 안 떠요

브라우저가 새 창을 막았을 수 있습니다. 주소 칸 오른쪽에 "팝업 차단됨" 표시가 보이면 눌러서 허용한 뒤 다시 연결해 주세요.

AI가 "기능을 찾지 못했다"거나 캡처를 보내 달라고 해요

이 대화에서 경충이 켜져 있지 않은 것입니다.

  • ChatGPT: 새 대화를 열고 입력 칸에 @를 쳐서 경충을 고른 뒤 다시 물어봅니다.
  • Claude: 입력 칸 왼쪽 아래 +의 Connectors에서 경충을 켭니다.

한 번 실패한 대화에서는 같은 답을 되풀이할 수 있으니 새 대화에서 해 보세요.

"권한이 없습니다"라고 나와요

경충 웹에서도 내가 할 수 없는 일입니다. 필요한 일이라면 운영진에게 부탁하거나 직책 권한을 확인해 주세요.

로그인이 안 되거나 비밀번호를 바꾸라고 나와요

경충 웹에 먼저 로그인해서 비밀번호 변경을 끝낸 다음 다시 연결해 주세요. 비밀번호를 잊었다면 운영진에게 문의해 주세요.

연결을 끊고 싶어요

ChatGPT는 플러그인 화면에서, Claude는 Connectors 화면에서 경충을 찾아 삭제하거나 연결 해제를 누르면 됩니다. 경충의 데이터는 지워지지 않습니다.

  • 저장하기 전에 미리보기를 읽습니다. 이름과 날짜가 맞는지 보고 승인해 주세요. 저장된 내용은 모든 회원에게 바로 보입니다.
